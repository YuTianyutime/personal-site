第 1 步

连接你的 GitHub 网站仓库

连接只需要做一次。密码令牌仅保存在你的手机浏览器中，不会上传到本网站。

如何获得令牌？
  1. 登录 GitHub，打开 Settings → Developer settings → Personal access tokens → Fine-grained tokens。
  2. 创建一个只允许访问个人网站仓库的令牌。
  3. 仓库权限只开启 Contents: Read and write。
  4. 复制令牌并粘贴到下方。令牌通常以 github_pat_ 开头。
