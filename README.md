# 余天宇个人主页

公开主页：https://yutianyutime.github.io/

手机管理页：https://yutianyutime.github.io/personal-site/admin.html

GitHub 仓库：https://github.com/YuTianyutime/personal-site

## 手机管理

1. 手机打开管理页。
2. GitHub 用户名填写 `YuTianyutime`。
3. 仓库名称填写 `personal-site`。
4. 分支填写 `main`。
5. 创建一个 Fine-grained personal access token，仓库权限只开启 `Contents: Read and write`。
6. 把令牌粘贴到管理页，点击“连接并读取网页”。
7. 修改文字、添加照片或替换头像后，点击底部“保存到网站”。

令牌创建页面：https://github.com/settings/personal-access-tokens/new

## 更新说明

点击保存后，内容会提交到 GitHub。GitHub Pages 通常需要 1–3 分钟完成更新。

## 注意

- 不要把访问令牌发给别人，也不要提交到仓库。
- 管理页的写权限完全由 GitHub 令牌保护。
- 建议定期使用“设置与备份 → 导出”保存一份内容备份。
